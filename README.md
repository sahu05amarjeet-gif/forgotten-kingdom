# 🏰 Forgotten Kingdom

A console-based Text RPG built using **Java**.

Enter the Forgotten Kingdom, explore mysterious places, encounter enemies, and fight turn-based battles. This project is part of my journey to improve my Java programming and Object-Oriented Programming skills.

## ✨ Features

- Player creation with customizable name.
- Player stats including health, attack damage, gold, XP, and level.
- Enemy encounters.
- Turn-based combat system.
- Player and enemy attack mechanics.
- Health tracking during battles.
- Option to run away from battles.
- Menu-driven gameplay.

## 🛠️ Tech Stack

- **Language:** Java
- **Concepts:** Object-Oriented Programming (OOP), Classes, Objects, Constructors, Encapsulation, Methods, Loops, Conditional Statements.
- **IDE:** IntelliJ IDEA

## 🚀 Getting Started

### Prerequisites

- Java JDK installed.
- Any Java IDE or terminal.

### Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/sahu05amarjeet-gif/forgotten-kingdom.git
   ```

2. Navigate to the project directory.

3. Compile the Java files:

   ```bash
   javac src/*.java
   ```

4. Run the game:

   ```bash
   java -cp src Main
   ```
